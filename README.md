Tic Tac Toe Game (JavaScript)

A simple Tic Tac Toe game built using HTML, CSS, and JavaScript.
This project was created while learning JavaScript to understand DOM manipulation, event handling, and game logic.

Features

Two player game (Player X and Player O)

Interactive game board

Detects winner automatically

Draw detection

Reset / Restart game button

Simple and responsive UI

Technologies Used

HTML

CSS

JavaScript

How to Run the Project

Download or clone the repository

git clone https://github.com/your-username/tic-tac-toe.git

Open the folder.

Double click index.html
or open it in your browser.

How to Play

Player X starts the game

Players take turns clicking empty squares

The first player to align 3 marks in a row (horizontal, vertical, diagonal) wins

If all squares fill and no winner → Draw
